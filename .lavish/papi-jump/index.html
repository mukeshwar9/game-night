HOW IT LOOKS — retro skin

  • Player: chunky pixel blob, cyan P1 / pink P2, squash on land, stretch on rise. Trail dots.
  • Platforms: normal neon-green slab, moving blue slab, breakable cracked amber (1 use), spring gold coil.
  • Backdrop: deep navy grid + parallax stars + scanline overlay. Height meter right rail.
  • HUD: pixel score top-left, ghost race bars top (YOU vs FOE), countdown 3-2-1-GO.
  • Audio: existing sounds boing / crack / spring — same bus as MineRace.
  • Themes: free via --c-* tokens. Phosphor green, synthwave sunset, mono 1-bit all work.

2P RACE FLOW — same as MineRace

  • READY → shared jumpSeed + jumpStartedAt → 3s countdown.
  • Both clients generate identical platforms from seed. Physics local 60Hz fixed timestep.
  • Sync only height + dead flag debounced 150ms. No positions — anti-leak, anti-cheat-lite.
  • Finish: both dead, or timer 90s, or one hits target. runTransaction sets winner + scores.
  • Spectators see both heights live via onValue.
