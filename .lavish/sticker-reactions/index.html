3 · FLOW + PERMISSIONS

keyboard / paste / file→ downscale 160px→ preview + SEND→ floats both screens
  • No OS permission needed. File picker + paste fire only on your tap — browsers already allow both. No manifest / PWA change.
  • No new server. Sticker rides the existing reaction node as a ~45KB data URL. Pruned like chat (30 cap).
  • Limits: source ≤ 5MB, sent ≤ 60KB, recents 6 per device. Junk/oversize → toast, never sends.
  • Sound: default reaction pop + haptic (custom packs have no mapped sound).
  • Honest limit: iOS Memoji-style keyboards insert into rich fields only — our chat box is plain text, so those specific stickers come via the image button, not the keyboard.
