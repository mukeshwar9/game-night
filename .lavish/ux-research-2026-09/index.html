02 / JOURNEYS

Where intent leaks.

New visitor

Welcome slogan before product value. Guest path still forces fighter identity before any game is visible. Risk: “INSERT COIN” reads like payment.

Solo intent

User already picked a game + VS AI. Deep link remounts a browse hub (Demo badge, category tabs, grid). Intent ignored; board delayed.

Host waiting

Source order: 150 px QR, then Share/Copy, then code. Mobile hosts usually need Share first; QR wins for co-located desktop.

Returning player

Continue Playing is high. Recently Played sits under the full catalog (~3374 px mobile scroll). Recents buried.

05 / FINDINGS

Six issues, ranked by play friction.

R-01
P0 Solo journey

Deep-linked solo still behaves like a browse hub.

/solo/tictactoe shows Demo badge, category tabs, and a dense game grid before the board. Captured first-viewport text is almost all picker labels. Board top ~179 px but competing chrome eats the fold.

Evidence: 05-solo.png, heuristics.solo. Source: Demo.jsx DemoHub (~2360–2428).

R-02
P0 A11y

Options sheet is not a keyboard modal.

On open, focus stays on the catalog card. Tab moves to “Add to favorites” behind the sheet. 115 background controls remain focusable while aria-modal="true".

Evidence: heuristics.focusOnOpen / focusAfterTab / backgroundFocusablesWhileOpen. Source: BottomSheet.jsx — Escape only; no focus trap / inert.

R-03
P0 Readability

Catalog metadata is below readable size; blurbs hidden on mobile.

Title 10 px pixel. Player tag 7 px. Duration 6 px. Description “three in a row wins” is display:none below sm. Search + room code use placeholder-only labeling.

Evidence: heuristics.firstCard + homeInputs. Source: GameCard.jsx, GamePicker.jsx, Home.jsx.

R-04
P1 Onboarding

Identity customization gates discovery.

Welcome → fighter avatar/name → catalog. Avatars are delightful, but they delay the product promise. “INSERT COIN” can imply payment.

Evidence: 01-welcome.png, 02-identity.png. Source: Onboarding.jsx.

R-05
P1 Copy / IA

Mode labels and chip row fight for meaning.

“PLAY ONLINE” = private room, not matchmaking. “2P PASS” less clear than “Same device”. Filters (Quick/Thinky/Solo OK) share one horizontal row with categories — early viewport crowded.

Source: GameOptionsSheet.jsx, GamePicker.jsx chipRow.

R-06
P2 Hierarchy

Home promotes everything; recents arrive late.

Repeated logo vs global nav. Daily + cramped code field. Emoji Lab beside brand. Notes as primary tab. Recently Played after full catalog. Playground CTA adds another destination before play.

Evidence: 03-home.png scrollHeight 3374. Source: Home.jsx, BottomTabBar.jsx.

Keep as-is

Midnight arcade identity, semantic --c-* themes, options sheet (explicit modes — no silent room create), Continue Playing, sticky search/filters, touch targets ≥44 px on invites/JOIN, reduced-motion support.

06 / PLAN

Three plan options. One recommended.

RECOMMENDED · SPRINT A

Play-friction sprint

  1. Board-first solo — valid /solo/:type shows game first; picker behind “Change game”; rename Demo→Solo. Keep /demo as browse hub.
  2. Sheet focus boundary — initial focus, Tab trap, background inert + scroll lock, restore opener. Own in BottomSheet.jsx.
  3. Readable discovery — mono 12–14 px meta; show one-line desc on mobile; visible labels on search + room code.

Out of scope: rebrand, onboarding rewrite, Firebase schema, game rules, mode-first IA.

ALTERNATE · SPRINT B

First-session clarity

  1. One-click guest with generated defaults; defer avatar.
  2. Replace INSERT COIN with free-play promise.
  3. Copy pass: Create a room / Play solo / Same device.
  4. Move Recently Played above full catalog.

Does not fix solo fold or modal focus. Pair with Sprint A, do not replace it.

Later · Sprint C (after usability check)

Home hierarchy trim (Emoji Lab / Notes secondary), optional mode-first browse with All-games reset, WaitingRoom share-first on mobile (capture live lobby first). Do not ship C without A.

Acceptance for Sprint A

  • 390×844: full Tic Tac Toe board + turn line visible without scroll on solo deep-link.
  • Sheet: focus inside on open; Tab/Shift+Tab wrap; background not focusable; Escape restores opener.
  • Cards: description visible on mobile; no 6–7 px pixel meta; labeled search + code fields.
  • Regression: /demo, /local, favorites, room create, theme tokens unchanged.
