1 · BOOP — quilt, kittens, push fights

BOARD 6×6board[36] 'kittenX'/'catX'…WOW ★★★★★3–5 MIN

PLAYABLE MOCK — TAP EMPTY QUILT CELL (X FIRST, AUTO-ALTERNATE)

Push demo: placing next to a kitten shoves it 1 cell (chain). Line up 3 kittens → they graduate to cats. 3 cats in row wins. Real logic: boopLogic.applyBoopMove().

  • Look: cozy quilt 6×6, rounded patches, cyan kittens 🐱 vs pink kittens 🐈, graduated cats bigger + glow.
  • Turn: place 1 kitten on empty bed → all adjacent kittens pushed 1 cell (cats can't be pushed).
  • Graduate: 3 kittens in row leave board, return as 1 cat. First to 3 cats in row wins.
  • Why nice: cutest game in catalog, zero overlap (only push game is LOA/Ataxx, neither cute), viral with couples.
  • Firebase: board string[36], currentTurn flips normally, extraTurn null. Win check = count cats lines.
board: string[36]  // '' | 'kX' | 'kO' | 'cX' | 'cO'
applyMove: place + push8(board, idx) + graduate()
getWinner: 3 'cX'/'cO' in row → X/O; else null

2 · GOBBLET GOBBLERS — nesting cups tic-tac-toe

BOARD 3×3 NESTEDboard[9] stacksWOW ★★★★☆2–4 MIN

PLAYABLE MOCK — PICK SIZE, TAP CELL (BIGGER GOBBLES)

  • Look: chunky 3×3 diner tray, orange vs blue cups S/M/L, gobble = big cup swallows small with bounce.
  • Turn: play a cup from hand onto empty cell or onto smaller enemy cup. Memory matters — hidden sizes under cups.
  • Win: 3 visible tops in row. Bluff + recall, kids learn in 30s, adults mind-game.
  • Why nice: only nesting game in catalog; TTT players upgrade path; phone taps huge.
  • Firebase: board = 9 stacks encoded "X2" (owner+size); hand counts per size; currentTurn flips.
board: string[9]  // '' | 'X0..X2' | 'O0..O2' (visible top)
+ gobHandX/O: [s,m,l] counts
applyMove: if size > top.size → cover
getWinner: 3 tops same owner in row

3 · TAK 5×5 — zen road-building duel

BOARD 5×5 + STACKSboard[25] stacksWOW ★★★★☆10–15 MIN

PLAYABLE MOCK — TAP TO LAY FLAT, W = WALL

Full Tak adds carry stacks + capstone crush. Mock shows placement + road idea; road = edge-to-edge chain wins instantly.

  • Look: dark walnut 5×5, ivory vs ebon flat stones, walls upright, road glows gold. Most premium thinky look.
  • Turn: place flat/wall from reserve, or move a stack carrying N stones dropping 1+ per cell. Capstone flattens walls.
  • Win: road connecting opposite edges, or flat-majority when board full / reserves out.
  • Why nice: deep-but-small; fills "chess-like prestige" gap next to Onitama/Quarto; streamers love it.
  • Firebase: board string[25] stacks "Xf3" style + reserves; currentTurn flips; road BFS in getWinner.
board: string[25]  // stack tops + height, e.g. 'Xf:3'
+ takReserveX/O, takCapX/O
applyMove: place | move-stack(drop pattern)
getWinner: BFS road X/O → winner; else flat count

4 · PYLOS — wooden pyramid race to top

PYRAMID 4·3·2·1spheres[30]WOW ★★★★★8–12 MIN

PLAYABLE MOCK — FILL BASE, THEN STACK (NEEDS 2×2 SUPPORT)

Bonus rule live here: close a 2×2 square of your color → take 1–2 spheres back (extra ammo). Top sphere wins.

  • Look: layered walnut pyramid, ivory vs walnut spheres with soft 3D radial shading, top plinth gold.
  • Turn: place from reserve onto base, or stack on a full 2×2 support, or promote a board sphere upward.
  • Bonus: square or line of own color → remove 1–2 spheres to reserve (economy engine). Sphere shortage loses.
  • Why nice: only 3D game in catalog; table presence huge; existing .lavish/pylos-concept already explores — this finishes it.
  • Firebase: board string[30] (4²+3²+2²+1), reserve counts; currentTurn flips except bonus-remove step.
board: string[30]  // layers [0..15|16..24|25..28|29]
+ pylosReserveX/O
applyMove: place | stack(support 2x2) | promote
getWinner: board[29] set → owner wins

5 · ABALONE — shove marbles off hex island

HEX 61 CELLSboard[61]WOW ★★★★☆10–15 MIN

PLAYABLE MOCK — TAP MARBLE TO SELECT, TAP ARROW TO PUSH

Full rules: 1–3 in line move together; 2 pushes 1, 3 pushes 1–2 (never equal numbers). 6 enemy marbles off wins. Mock = 1-row shove feel.

  • Look: slate hex island, glossy white vs black marbles, eject track on rim counts fallen marbles.
  • Turn: move 1–3 own marbles 1 hex; Sumito push when attackers outnumber defenders in line.
  • Win: first to eject 6 enemy marbles. No luck, pure positional wrestling.
  • Why nice: only hex-push game (Hex is connect-only); tactile + dramatic; great vs Checkers/Mancala crowd.
  • Firebase: board string[61] 'X'/'O'; ejected counts; currentTurn flips; no extraTurn.
board: string[61]  // '' | 'X' | 'O', hex coords
+ abaOutX/O: ejected counts
applyMove: { line:[a,b,c], dir } + sumito check
getWinner: abaOutO==6 → X wins (and reverse)
