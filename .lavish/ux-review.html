04 · TOP IMPROVEMENTS

Current vs proposed — highest leverage first

1 · RIVALRY ON WIN SCREEN

NOW

H2H line exists but uses text-retro-dim at 9px — fails contrast, easy to miss. 3–0 and 3–2 share identical celebration.

PROPOSED

Prominent rivalry chip under score: "4–2 VS SAM" + margin badge on close games. Same data, stronger visual hierarchy.
EFFORT TrivialIMPACT Retention + satisfaction

2 · SOLO RULES PARITY

NOW

Catalog has rules "?" button. /solo/:type and Demo drop player on bare board — no rules affordance for Hex, Blockade, etc.

PROPOSED

Add RulesButton next to demo header in Demo.jsx. Same modal, zero new content. Matches Home "how it works" promise.
EFFORT SmallIMPACT Clarity for solo path

3 · FIX --c-dim CONTRAST

NOW

text-retro-dim fails 4.5:1 on card in 5/6 themes. Used in 106 files at 7–10px for descriptions, labels, empty states.

PROPOSED

Raise dim luminance ~15% per theme OR add --c-dim-aa for readable secondary text. Audit decorative vs informational uses.
EFFORT MediumIMPACT A11y critical

4 · WAITING ROOM SIGNAL

NOW

Static "WAITING FOR OPPONENT" + share link. No feedback if link opened, no elapsed time, creator sits in silence.

PROPOSED

Lightweight viewer ping ("Someone opened the link") + optional invite-friend CTA above fold. Reduces session death before seat fills.
EFFORT MediumIMPACT Conversion to 2P

5 · MODAL FOCUS TRAP + BACK GESTURE

NOW

BottomSheet has no focus trap. useModalHistory stubbed — Android swipe-back exits room instead of closing sheet.

PROPOSED

Restore M-06 history hook + small useFocusTrap on sheet open. One fix covers Rules, Invite, Switcher, Emote picker.
EFFORT Low–MediumIMPACT Mobile + keyboard

6 · HOME INFORMATION DENSITY

NOW

Home stacks logo, invites, daily, join, how-it-works, continue, full catalog, solo CTA, playground, stats, nudges, install — long scroll before repeat play.

PROPOSED

Collapse returning-user Home: Continue Playing + compact recents first; tuck catalog below fold or "Browse all". Progressive disclosure by visit count.
EFFORT MediumIMPACT Time-to-play
