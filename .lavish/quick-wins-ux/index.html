51f639d Test two players on one computer 37 files · +703/−113

Until now, testing a 2-player game on one browser was awkward: two normal tabs share the same identity, so the "second player" had to use a private window. This feature fixes that. Testing tools (like Chrome DevTools MCP) can now drive several real players in plain tabs.

  • How to start it — run npm run test:emulators (starts fake Firebase servers on your machine) and npm run dev:test (the dev server with testing switched on). No real Firebase account or .env.local needed for this mode.
  • The launcher — the browser shows a screen with buttons P1–P8 and SPECTATOR. Each button opens a normal new tab that acts as that player, with its own identity.
  • Each slot is a real player — each tab signs in to the local fake Firebase and gets its own user id. Opening P1 again later gets you the same P1 back. The URL decides the slot (?devPlayer=p1), so one tab can never steal another tab's identity.
  • Private storage per player — names, stats, room history, seat records, and every secret (the hidden battleship fleet, the hangwoman word, etc.) are stored under separate keys per slot. Two tabs can't read each other's data. Things that should stay shared (theme, sound settings) are still shared. The normal keys are untouched when this mode is off.
  • Safe limits — the SPECTATOR slot can watch but never takes a seat. Signing in with Google is switched off in this mode. The mode only works on your own machine during development — the live website and normal dev server ignore it completely.
  • A badge shows the state — a small corner tag shows the slot, the player id, and whether the fake servers are up (EMU-OK / EMU-DOWN).
  • Docs — step-by-step test walkthroughs for 2-player and party games are in docs/DEV-MULTIPLAYER.md. README and AGENTS.md mention it too.
  • STILL OPEN — the plan says the real test must be done by hand with the emulators running. That walkthrough has not been done yet. The code-level pieces (the small logic parts) are covered by 17 new automated tests.
